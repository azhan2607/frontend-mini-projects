# Image Gallery

A responsive image gallery built with HTML, CSS, and JavaScript. It lets visitors browse image collections, filter them by category, and open images in a larger lightbox view.

## Features

- Responsive CSS Grid layout for different screen sizes
- Category filters: All, Nature, City, and Animals
- Hover effects and image captions
- Lightbox preview for a larger view of an image
- Previous and next navigation in the lightbox
- Keyboard navigation with the arrow keys and Escape
- Mouse-following animated background effect

## Technologies Used

- HTML5 for page structure
- CSS3 for layout, responsiveness, and visual effects
- Vanilla JavaScript for filtering and lightbox interactions
- Remote sample images from Picsum

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/azhan2607/frontend-mini-projects.git
   ```

2. Open the project folder:

   ```bash
   cd frontend-mini-projects/image-gallery
   ```

3. Open `index.html` in your browser, or open the repository in Visual Studio Code and use the Live Server extension.

No build tools or package installation are required.
