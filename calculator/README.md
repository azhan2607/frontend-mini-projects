# Calculator

A browser-based calculator with a glassmorphism interface, built using HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage calculation
- Clear all (AC) and delete last character (DEL)
- Decimal number input
- Keyboard support
- Animated particle background
- Responsive calculator layout

## Technologies Used

- HTML5 for structure
- CSS3 for the glassmorphism design and layout
- Vanilla JavaScript for calculator operations and interaction
- HTML Canvas for the animated particle background

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/azhan2607/frontend-mini-projects.git
   ```

2. Open the calculator folder:

   ```bash
   cd frontend-mini-projects/calculator
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No build tools or package installation are required.
